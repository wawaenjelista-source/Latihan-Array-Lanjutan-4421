## Deskripsi

Repository ini berisi latihan dasar penggunaan Array dalam JavaScript, meliputi pembuatan Array, mengakses dan mengubah elemen, serta penggunaan properti `length`.

## Daftar Latihan

- Soal 1 — Antrean Siswa
- Soal 2 — Daftar Buku
- Soal 3 — Pencarian Peserta
- Soal 4 — Pengolahan Nilai
- Soal 5 — Perlengkapan Kelas

## Cara Menjalankan Program

1. Buka folder proyek menggunakan Visual Studio Code.
2. Buka Terminal.
3. Jalankan file JavaScript menggunakan Node.js.

Contoh:

```bash
node soal-1.js
```

Ganti nama file sesuai soal yang ingin dijalankan.
